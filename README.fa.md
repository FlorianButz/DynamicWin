## ✨ چی کار می‌کند

یک قرصِ شیشه‌ایِ واحد بالای صفحه می‌نشیند و بی‌سروصدا کارهایی را که مدام سراغش می‌روی انجام می‌دهد — چی در حالِ پخش است، نوتیفی که همین الان آمد، فایلی که می‌خواهی بینِ پنجره‌ها جابه‌جا کنی — بدونِ بازکردنِ اپ یا پوشاندنِ کارت.

- 🎵 **مدیا** — «در حال پخش» با موجِ زنده، کاورِ آلبوم (یا گیفِ متحرک)، و کنترلِ کامل: پخش، جابه‌جایی، صدا؛ برای ویدیو هم ±۱۰ ثانیه، سرعت، و زیرنویس.
- 🔔 **نوتیف‌ها** — هر نوتیف با آیکونِ واقعیِ همان اپ داخلِ قرص میفتد. بزنش تا باز شود، یا نوارِ پایینش را بکش تا متنِ بلند کامل باز شود. کدِ تأیید (۶ یا ۸ رقمی) یک دکمهٔ **کپیِ** یک‌کلیکی می‌گیرد.
- 📁 **File Tray** — فایل را روی قرص بکش تا نگه‌داری شود، بعداً بکشش بیرون توی هر پنجره‌ای.
- 🔋 **بلوتوث** — هدفون، دسته، یا گوشی که وصل شود، قرص چند ثانیه رینگِ باطری و درصدش را نشان می‌دهد.
- 🤖 **Claude Code و Codex** — یک پنلِ زنده برای هر سشن: مصرفِ توکن، محدودیتِ ۵ساعته و هفتگی، وضعیتِ اتصال، و یک Cancel که واقعاً پرامپتِ در حالِ اجرا را متوقف می‌کند.
- ⬇️ **دانلودها** — پیشرفت همان‌جا توی قرص، با دکمهٔ استاپ.
- 📌 **پین** — قرص را هر وقت خواستی بالای اپ‌های تمام‌صفحه و توی ضبطِ ویدیو نگه دار.

شیشهٔ آکریلیکِ واقعی، انیمیشن هماهنگ با نرخِ رفرشِ مانیتور (۱۲۰/۱۴۴ هرتز)، از صفر با C# روی Windows.UI.Composition ساخته شده.

| دانلود | چیه |

| **DynamicWinSetup.exe** | نصب‌کننده — per-user، بدونِ پرامپتِ ادمین |
| **DynamicWinPortable.zip** | پرتابل — اکسترکت کن و `Halo\Halo.App.exe` را اجرا کن |
